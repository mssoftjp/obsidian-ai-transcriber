# AI Transcriber 0.11.4

- Restore duration and range-end values for audio/video files above 16 MiB by reading media metadata independently of the optional waveform preview.
- Preserve existing unmarked temporary folders and continue external-file imports in a separate owned folder, including cleanup after restart.
- Recover from temporary HTTP 429 errors with at most two retries and 60 seconds of automatic waiting per call. Respect server cooldowns across concurrent and subsequent chunks; do not automatically resend requests after local timeouts, network failures, HTTP 408/5xx, or quota/billing errors.
- Add synthetic regression coverage for media duration, time-range routing, WMA v1/v2 decoding, safe temporary-file cleanup and bounded rate-limit recovery. Run real-media tests in CI before publishing releases.

## 修正内容

- 16 MiBを超える音声・動画でも長さと範囲終了時刻を表示できるよう修正しました。
- 既存の一時フォルダを保持し、別の管理フォルダで外部ファイルの取り込みと清掃を継続します。
- 一時的な429エラーの再試行と、後続チャンクへの待機を復元しました。処理結果が不明なエラーや残高・利用枠不足は自動再送しません。
- 実メディアの回帰テストを公開し、リリース前のCIチェックに追加しました。
