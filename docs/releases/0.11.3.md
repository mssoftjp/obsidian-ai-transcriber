# AI Transcriber 0.11.3

## Changes

- Compile the local WMA runtime for Web Workers only, removing unused Node.js filesystem and crypto support.
- Keep the WMA decoding WebAssembly unchanged and retain all third-party license notices.
- Add a regression check that prevents Node module loaders from returning to the shipped WMA worker.
