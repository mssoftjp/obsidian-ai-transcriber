# AI Transcriber 0.11.2

- Decode WMA Standard (wmav1/wmav2) locally with bundled WebAssembly. WMA Pro, Lossless, Voice and DRM-protected files are unsupported.
- Recover eligible M4A recordings through original-file upload when local decoding fails before transcription begins.
- Prevent duplicate chunk requests and strengthen cancellation, media memory limits, temporary-file cleanup and error reporting.
- Use native Obsidian modal titles and section headings; namespace the loading animation and remove unused legacy modal CSS.

The distribution contains main.js, manifest.json and styles.css. No decoder download is required.
