# AI Transcriber 0.10.0

## Changes

- Improved GPT-4o and Whisper chunk-boundary merging to reduce duplicated or missing text
- Added direct uploads for eligible GPT-4o transcription requests
- Added Opus/WebM compression for processed chunks with WAV fallback
- Updated the AI post-processing model to GPT-5 Mini
- Fixed long transcripts being truncated during AI post-processing
- Applied contextual dictionary corrections only when AI post-processing is enabled
- Removed server-side VAD and migrated existing settings to **No processing**
- Continued transcription when local VAD initialization fails
- Improved interface descriptions for models, VAD, dictionary correction, and pricing
- Fixed audio-range processing and cost estimates
- Improved cancellation, temporary-file cleanup, job serialization, external-file handling, and note saving
- Strengthened API key storage and migration of existing keys
