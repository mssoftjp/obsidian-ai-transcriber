# 文字起こしモデル説明文の改善

## 目的

設定画面で、各文字起こしモデルを選ぶ理由が短い説明だけで分かるようにする。

## 表示文言

日本語では次の説明を表示する。

- Whisper-1：タイムスタンプ出力を選択可能
- GPT-4o Transcribe：最高精度
- GPT-4o Mini Transcribe：Whisperより高精度・低コスト

英語、中国語、韓国語も同じ意味になるよう更新する。

## 変更範囲

- 4言語のモデル説明用翻訳文字列だけを変更する。
- モデル名、選択肢、価格計算、APIモデルID、文字起こし処理は変更しない。
- 既存の3行リスト表示とレイアウトは変更しない。

## 検証

- 4言語すべての説明文が期待値と一致するテストを追加または更新する。
- lint、build、全テスト、生成物lintを実行する。
- Obsidianプラグイン配置先を差し替え、ビルド結果との一致を確認する。
